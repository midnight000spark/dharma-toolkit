# Дхарма-тулкит

Универсальный мобильный тулкит буддийских практикующих: календарь особых дней,
счётчики практик, тексты. MVP: Ньингма + Тхеравада. Русский язык, offline-first,
без бэкенда и трекинга.

## Статус
Этапы 0–4 закрыты (переоткрыты аудитом 2026-08-31, перекрыто в 5.0.2; долги B-1…B-11
закрыты в подэтапе 5.0). Этап 5: подэтап 5.0 ✅, спайк 5a ✅ (порт тибетского календаря
Пхугпа, 0 расхождений на 731 векторе), 5b.0–5b.6 ✅ — абстракция
CalendarProvider (5b.1), упосатхи (5b.2), тибетский провайдер 10/25 + Лосар (5b.3),
выбор календаря по тегу активного пресета (5b.4), персистентность закрыта замером —
таблица не вводится (5b.5, F-51), мутационная самопроверка 5b.1/5b.2 и печатаемый
сценарий SCR-11 (5b.6); 229 тестов зелёные. Подробности — в STATE.md.
Остаток этапа 5: ручная приёмка подэтапа 5b и тег stage-5b; экран календаря — Этап 8.
