### D-1: Схема классификации [гипотеза][факт][решение][угроза]
- **Причина**: Структурированный подход к управлению знаниями при сжатии контекста
- **Альтернативы**: Свободная форма заметок
- **Дата**: 2026-08-26

### D-2: Flutter как основной фреймворк
- **Причина**: Лучшая поддержка модульности, строгая типизация, Drift для SQLite
- **Альтернативы**: React Native, Kotlin Multiplatform
- **Дата**: 2026-08-26

### D-3: Кастомный агент dharma вместо plan/build
- **Причина**: Нужен primary-агент с авто-перечитыванием STATE.md и AGENT.md
- **Альтернативы**: Использовать встроенных агентов
- **Дата**: 2026-08-26

### D-4: Riverpod — единственная система DI, get_it исключён
- **Причина**: Riverpod покрывает и state management, и DI; get_it избыточен
- **Альтернативы**: get_it + injectable, ручная DI
- **Дата**: 2026-08-26

### D-5: Модульность = изоляция папок + архитектурные guard-тесты импортов; рантайм-плагины невозможны из-за AOT-компиляции; конфигурируемость через JSON-пресеты
- **Причина**: Flutter AOT не поддерживает динамическую загрузку кода; модульность достигается через структуру папок и контроль зависимостей тестами
- **Альтернативы**: Рантайм-плагины (невозможно в AOT), monolith
- **Дата**: 2026-08-26

### D-6: Offline-first, без бэкенда и аналитики; данные локально
- **Причина**: Приватность практикующих, работа без интернета
- **Альтернативы**: Облачный бэкенд, синхронизация
