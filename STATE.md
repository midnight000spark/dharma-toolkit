### R-24: moon_phase.dart — сомнительная транскрипция рядов Мееуса при цитате «гл. 33» (быв. PROB-6)
- **Описание**: `moon_phase.dart:63-91`: аргумент `2d+mp` встречается в рядах дважды (−0.114 и +0.053) — в исходных рядах Мееуса аргументы уникальны, почти наверняка опечатка в члене; аргумент `fd` (D′, вековая скорость 39.1°/т) для широты выглядит подменой F′; комментарии описывают алгоритм, которого код не реализует. Оценочно на суточную точность не влияет (ошибки ~0.05° ≈ 0.02 дня; широта в схеме «полдень UTC → ближайший день» структурно не сдвигает даты четвертей) — эмпирика зелёная: 149/149 векторов ±1 день.
- **Вероятность**: высокая, что опечатка есть (неуникальность аргументов ряда)
- **Влияние**: среднее (потолок точности при подъёме до «моментов фаз» — будущий SCR-11; ложь в комментариях)
- **Митигация**: построчная сверка строк 69-91 с Meeus Table 33.a/33.b, исправление коэффициента/аргумента и комментариев; биекционный тест 149 событий (F-49) обязан остаться зелёным после правки.
- **Статус**: открыта

### R-25: «CI зелёный» было непроверяемым утверждением агента (зависело от живого gh-токена)
- **Описание**: приёмка этапа требует зелёного CI (сквозные правила ROADMAP, AGENT),
  но инструмент чтения статуса — `gh` — оказался мёртв: ключ в keyring невалиден после отзыва
  PAT (наследие F-41), `gh api user` → 401. Пуш/клон это не задевает (remote на SSH),
  а вот «✅ CI зелёный» повисло бы как вера в веб-UI, то есть как прямое нарушение
  общего правила приёмки («каждое ✅ подтверждается командой проверки»). В пакете 5b.5
  сначала так и вышло: отчёт говорил «CI не подтверждён агентом», хотя статус читался
  анонимно (репозиторий публичный).
- **Вероятность**: высокая (реализовалась в 5b.5)
- **Влияние**: среднее (ложные ✅/⏳ в приёмке этапа; потеря времени на ручные проверки)
- **Митигация**: `scripts/ci_status.sh [ref] [--steps]` (D-33) — анонимный публичный API
  GitHub, exit 0/1, печатает ран и шаги; включён в правило приёмки AGENT v2.11.
  Остаточные ограничения: анонимный лимит 60 запросов/ч на IP, приватизация репозитория
  сломает обходной путь (нужен живой токен), `gh` по-прежнему требует интерактивного
  `gh auth login -h github.com` — это действие оркестратора, не пакета.
- **Статус**: в работе (митигирована скриптом; полный починк gh — за оркестратором)
