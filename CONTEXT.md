# Быстрый контекст проекта "Дхарма-тулкит"

## Суть проекта
Мобильное приложение — универсальный буддийский тулкит. Поддерживает Тхераваду, Махаяну, Ваджраяну, Бон. Пользователь выбирает традицию, получает настроенный набор инструментов: календарь, счетчики практик, контент.

## Архитектура
- **Модульная**: ядро + плагины (календарь, счетчик, контент)
- **Конфигурируемая**: традиции = JSON-пресеты
- **Изолированная**: данные разных традиций не смешиваются

## Технологический стек
Flutter + Dart, Riverpod, Drift (SQLite), get_it, go_router
